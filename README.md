Numbering in RAP

<img width="656" height="413" alt="image" src="https://github.com/user-attachments/assets/c4d85aa5-eac5-46e1-b1ac-4c82d1a7d0bb" />

<p>Context:</p>
<p>External - from UI</p>
<p>Internal - not from UI</p>

<p>Managed - generated by the framework</p>
<p>Unmanaged - developer redefines methods and writes logic</p>

<p>Managed Internal Early numbering - It is managed and internal, meaning, framework generates the value and not from UI</p>
<p>BDEF code</p>  
  <p>field ( numbering : managed ) field_name</p>

<p>Unmanaged Internal Early numbering - Again not from UI but unmanaged, meaning, developer redefines method and assigns value</p>
<p> BDEF code </p>
<p>early numbering must be specified at entity header level</p>
<p>field ( readonly ) field_name</p>
<p>BP code</p>
<p>redefine and implement FOR NUMBERING method</p>

<p>In late numbering, user cannot provide value from UI, it is always Unmanaged Internal Late numbering.</p>
<p>BDEF Code</p>
<p>Late numbering must be specified at entity header level</p>
<p>BP code</p>
<p>redefine and implement adjust_numbers method</p>
