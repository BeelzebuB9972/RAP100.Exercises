Context:
External - from UI
Internal - not from UI

Managed - generated by the framework
Unmanaged - developer redefines methods and writes logic

Managed Internal Early numbering - It is managed and internal, meaning, framework generates the value and not from UI
Unmanaged Internal Early numbering - Again not from UI but unmanaged, meaning, developer redefines method and assigns value

In late numbering, user cannot provide value from UI, it is always Unmanaged Internal Late numbering.
